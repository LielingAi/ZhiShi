# range-ops —— 靶场连接与操作规范

## 接入：具名环境，不裸连

```bash
zhishi env add --kind ssh --id <名字> --host <靶机IP> --user <用户> --key-path ~/.ssh/id_ed25519
zhishi env open <名字>     # 在嵌入式终端打开会话（自动带 env 边界标记）
```

每个靶机/靶场一个具名环境，`zhishi env list` 可查。终端带 env 标记（`range:<host>`），界内操作自动放行、界外拦截——**不要绕过具名环境直接 ssh**，那会丢掉边界标记和审计。

## 授权边界纪律（红线）

- **只打授权目标**：目标在授权范围内才动手。范围不清先问，不假设。「顺手扫一下隔壁段」是越权。
- **出向流量可审计**：从本机/环境出去的流量走 D14 出向控制，可审计可回溯；不想法绕过它。
- 突破/提权/横向的每一步问自己：这动作在授权范围里吗？出向允许吗？

## 长时间任务挂 CronTask

扫描、监听、守株待兔类长任务不要占着当前会话硬等——挂 **CronTask**（`zhishi task create-direct --executionMode recurring ...`，见 zhishi-cli skill）后台跑，结果落工作区文件，主会话定期收割。会话是交互面，不是长跑容器。

## 痕迹管理

- **清理上传物**：传到靶机上的工具、脚本、临时文件，任务结束删掉——留在靶机上的工具是别人的 IOC，也是你的指纹。
- **退出会话**：干完活退出 SSH 会话/关掉 shell，不留挂起的登录态。
- 操作记录落工作区（命令、发现、凭据线索），靶机上只留「必须留的」。

## 凭据纪律（D-T4）

- 具名环境里**只存 keyPath 引用**（`--key-path` 指向私钥路径），**不存密码**——配置里出现明文密码即事故。
- 打进靶场过程中拿到的凭据/令牌属研究材料，记在工作区笔记里，不写进环境配置。
