# zhishi TUI 设计说明（定稿）

> 版本：2026-08-16 定稿。替代同日早前版本（多环境/气泡卡片稿作废）。
> 配套：`tui_tech_spec.md`（技术底账与契约边界）；`prototype.html`（按本稿重做）。
> 决策依据：D13（CLI 一等、删 GUI）、D14（边界安全+留痕，不是操作审批）、D15（全屏 TUI、控制四要素）、D17（环境主权），及 2026-08-16 四项拍板：
> ① **单环境深潜**——不做多环境并发视图（多环境 = 混乱，聚焦式研究效率最高）；
> ② **输入行即操作面**——`/` 动词 + `@` 名词承载一切配置与操作；
> ③ **无本地工作区**——只有环境概念，启动即选环境或新建环境（已登记 **D27**，产品方案 §5 同步修订）；
> ④ **渲染栈自研 mini-renderer**（2026-08-16 技术拍板，替代 Ink 方案）——行缓冲 + 脏行 diff + 帧调度，地基复用 `ansi.ts` 宽度数学，零新增依赖（低维护成本优先；Ink 在无模式回看/折叠块内滚动/optimistic 插入三个硬交互上弱区明显）。
>
> **同日修订**：Esc Esc 拆解（见 §6.1）——「回思路」改 `Ctrl+Z`，对话 rewind 与环境快照回滚解耦（原子回滚要求每消息一个快照锚点，VM 快照秒级重操作不可行）；五项服务端配套工作列入 §11（subagent 事件生产、steering 接线、`@` 注入解析、snapshot/rollback 端点、越界 ask 通道）。

## 1. 设计立场：深潜，单线程

研究员最稀缺的资源不是算力、不是工具，是**连续的注意力**。一次 exploit 迭代要在大脑里同时装着栈布局、寄存器状态、Canary 位置——任何一块常驻 UI 在展示「别的事」，都是从这张工作记忆里偷东西。

> **一块屏幕，一个研究线程。屏幕上不存在任何与当前问题无关的常驻信息。**

- 对照物不是 chat app，也不是 htop/k9s（监控工具为多目标而生），是 **gdb TUI / vim / less**——单对象深度操作的工具，研究员进入心流时实际使用的形态。
- D15「看得见」的正解：**你需要看的东西零滚动就在眼前；你不需要看的东西不占一个字符。** 不是把所有东西摆出来。
- 切换研究线程是**有成本的有意动作**（resume 语义，task.md + 快照保鲜）。有成本是特性：它让「先把手头这段调完」成为默认行为。廉价切换制造多任务幻觉，实际产出两个半成品。

界面是控制面不是价值面（D15）；控制四要素（看得见/插得进/停得下/批得准）是本稿的验收标尺。

## 2. 世界模型：只有环境

研究员的世界里只有环境。宿主上没有工作区、没有文件、没有任何研究对象——宿主只是他坐着的那把椅子（控制面 + 运行时 + 提取收件箱）。

- **正门两动词**：启动屏只做两件事——**选**（进环境）或**建**（从环境类型创建）。没有第三个世界，没有「仅工作区控制面」（本地工作区思维的残留，删）。
- **对象全在环境内**：代码、task.md、崩溃件、flag、fuzz 产物——`@` 补全搜的是环境的文件系统与产物清单，不碰宿主。拖文件进 TUI = 宿主→环境写入，直接进。
- **成果过界**：产出要落地必须过界提取（D14「产物提取检查」由此进入日常肌肉），或快照留环境明天 resume。没有第三种存放。
- 提示符锚点 `pwn@docker ❯` 是唯一事实：你看到的一切都发生在这个环境里。

全链路：**正门进环境 → 环境内深潜（说/做/指）→ 中断五档 → 过界提取 → 销毁或快照**。零「本地」概念。

## 3. 布局：chrome 两行

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│                    会话流（全部高度给它）                    │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ pwn@docker ❯ ▌                                             │ ← 输入
├────────────────────────────────────────────────────────────┤
│ ◐ 运行中 · 队列1 · 12% · deepseek-v4-pro │ ⛁ fuzz·3 │ Esc 停│ ← 唯一一行状态
└────────────────────────────────────────────────────────────┘
```

没有标题栏、没有环境带、没有侧栏。单环境之后「我在哪」一次回答就够——环境锚点长在输入提示符上，状态一行沉底，屏幕 90% 以上归会话流。

状态行三段：左 = 会话状态（◐运行中 / ○空闲 / ⏸已中断）+ 队列 + 上下文%；中 = 后台任务静态段（§8）；右 = **此刻 Esc 的含义**（§6.2）。窄屏裁剪顺序：模型 → 队列 → 上下文%，Esc 语义永不裁。

## 4. 视觉语言：仪器感五律

1. **无气泡。** 消息不用卡片包裹，行首符号 + 悬挂缩进：`❯` 你（琥珀）、`⏺` 助手（正文色）、`⚙` 工具（紫）。气泡是 chat app 的语言，仪器用列和缩进。
2. **红色唯一。** 全产品只有越界确认用红边框、错误用红 `✗`。界内没有任何红色事件——sqlmap 跑起来不红、exploit 打出去不红（D14：界内全自动零打扰）。红色一旦出现，余光就知道「这个不一样」。
3. **绿色唯一。** 绿只给成果：`✔ flag{...} → /work/flag.txt`。工具完成用灰 `✔`——「命令跑完了」不是成果。
4. **四色封顶。** 强调色只有 cyan（环境/连接）、amber（你/中断）、purple（工具）、红绿（稀缺）。其余全部灰阶。
5. **零常驻动画。** 只有当前动作一个 spinner；后台任务用静态符 `⛁`，不呼吸不闪。**任何在动的像素都在请求注意力。**

附加律：**折叠一切过程。** 思考块、工具输出、搜索中间结果默认折叠成一行摘要，关键信号（exit code、崩溃信号、flag 模式、端口命中）自动提取到摘要行；`Ctrl+O` 展开。折叠不是省空间，是保护注意力不被中间态淹没。

终端映射：TrueColor → 256 → 16 降级；不用斜体/圆角/阴影（终端能力不可控，且与仪器感相悖）。

## 5. 会话流元素规格

| 元素 | 形态 |
|---|---|
| 用户消息 | `❯` 琥珀 + 正文 |
| 助手消息 | `⏺` + 正文（Markdown：列表/行内 code/代码块带左侧紫竖条） |
| 工具卡（折叠态） | 一行：`⚙ env_exec · ✔ SIGSEGV at 0x41414141 · 1.2s`——关键信号在摘要行读完 |
| 工具卡（展开态） | 参数 + 输出，长输出内部滚动；`Ctrl+O` 折叠/展开 |
| 思考块 | 一行灰 `⏵ thought · 4s`，默认折叠 |
| 中断分隔线 | `── ⏸ 已中断 14:32 · 3 个工具结果已保留 ──`（optimistic：按下 Esc 瞬间插入，不等服务端回包） |
| 后台回报行 | `⏺ [fuzz-runner 回报] 7 崩溃去重后 3 个，crash-01 可达 EIP。要我切过去处理吗？` |
| 错误条 | `✗ 工具 reverse_shell 被边界规则拒绝（env≠host）。已跳过，不影响后续。` |
| 越界确认模态 | 见 §6.6——全产品唯一红边框 |

## 6. 交互

### 6.1 中断五档（产品方案 §4.2 的键位落地）

| 档 | 动作 | 键位 | 体感 |
|---|---|---|---|
| 停动作 | 中断当前 turn | `Esc` | 瞬时反馈：分隔线立刻插入，状态点变琥珀，不等回包 |
| 纠偏 | 改方向 | **直接打字** | 运行中输入永远可用，发送即 steering（pi steering 队列），不中断不等待 |
| 回思路 | 回退到任一历史消息 | `Ctrl+Z` | 对话 rewind（有快照锚点则提示可 `/rollback`）；环境回滚解耦，不捆绑 |
| 回环境 | 环境快照回滚 | `/rollback @snap` | 精确回到某个环境状态 |
| 接管 | 自己动手 | `/attach` | TUI 挂起、全屏进入该环境的 shell（像 vim 的 `:shell`），`exit` 回到 TUI 一切原样 |

**修订（2026-08-16）**：原「Esc Esc 原子回滚」拆解——①原子性不可行：每消息一快照锚点，docker 提交便宜但 VM 快照是秒级重操作，turn 内十几条命令不可承受；②Esc Esc 与「中断瞬时性」硬矛盾（单 Esc 要等双击消歧窗口才能发），故回思路改 `Ctrl+Z`，中断保持瞬时。后两档是与一切「单终端 agent」竞品的分水岭：它们的环境就是你的终端，我们的环境可快照、可进入。鼓励试错的最好方式是让试错便宜。

### 6.2 Esc 语义提示

Esc 有多义（弹层取消/回看回底/中断）是诚实的事实。解法不是发明复杂优先级，而是**状态行右端永远显示此刻 Esc 的含义**：`Esc 停` / `Esc 取消` / `Esc 回底`。研究员扫一眼就确定按下去会发生什么——可预期性就是手感。优先级本身：弹层 > 回看 > 中断。

### 6.3 回看：没有模式

废掉「回看模式 + 输入禁用」。模型取自聊天软件而非 less：**上滚即暂停追底，输入永不锁定**。视口离开底部时新消息不拽你下去，右下角浮 `↓ 3 条新消息`；滚到底自动恢复。一边翻 agent 的探测过程一边打纠偏指令——「看历史」和「插话」同时成立，这正是「插得进」。

### 6.4 输入行即操作面：说 / 做 / 指

研究员只做三件事，同一行完成：

```
说：pwn@docker ❯ 帮我看下这个崩溃是不是可控的
做：pwn@docker ❯ /rollback @snap-clean
指：pwn@docker ❯ 对比 @crash-01 和 @crash-03 的 RIP
```

**`/` = 动词**（所有动作与配置；配置不进界面、进命令，没有设置屏）：

| 组 | 命令 |
|---|---|
| 环境 | `/attach` `/rollback @snap` `/snapshot [名]` `/env`（换环境） |
| 线程 | `/fork` `/rewind` `/resume` `/compact` |
| 任务 | `/bg`（转后台）`/tasks`（看一眼即散） |
| 配置 | `/model` `/reset` `/export`（导出会话为报告） |

命令清单刻意保持短：能用自然语言说的不设命令，命令只留给需要精确性的动作（回滚到哪个快照、attach 哪个环境）。命令面膨胀是 TUI 慢性病，定期审视删减。

**`@` = 名词**（把环境里真实的对象拉进对话；对 LLM 是 grounding——注入内容/元数据，不是提名字）：

| 对象 | 注入什么 |
|---|---|
| `@exp.py` 文件（环境内） | 内容（大文件给头尾 + 行数） |
| `@pwn-docker` 环境 | 元数据：基底、快照点、挂载、运行状态 |
| `@fuzz` 后台任务 | 状态卡：时长、产出计数、最近结论 |
| `@crash-01` 环境产物 | 摘要：信号、寄存器、回溯头几帧 + 文件指针 |
| `@task.md` 状态卡 | 已验证事实/当前假设/死路清单 |
| `@snap-clean` 快照 | 元数据（配合 `/rollback`） |

输入 `/` 或 `@` 弹模糊搜面板（按类型分组），↑↓ 选、Tab 补、Enter 定、Esc 取消；**面板是临时的，选完即消失**。三种输入共用同一行、同一套补全、同一条历史（`Ctrl+R` 模糊搜）。

### 6.5 键位总表

| 键 | 作用 |
|---|---|
| `Esc` / `Ctrl+Z` | 停动作 / 回思路（含义见状态行右端） |
| `Ctrl+C` | 清输入行；空行双击退出 |
| `Ctrl+O` | 折叠/展开当前块 |
| `Ctrl+R` | 历史模糊搜 |
| `Tab` | 补全（`/` 命令、`@` 对象） |
| `Shift+Enter` | 换行 |
| `PgUp` / 滚轮 | 回看（无模式） |
| `Ctrl+L` | 重绘 |

ESC 消歧：支持 kitty keyboard protocol 的终端零延迟；ConPTY/老旧终端保留短超时 fallback（tech spec §6.7 的修正）。

### 6.6 越界确认（批得准的唯一模态）

```
┌─ ⚠ 越界 · 环境→宿主提取 ──────────────────────────┐
│ 把 pwn-docker 的 /work/flag.txt、/work/exp.py      │
│ 提取到宿主 ~/captures/2026-08-16-pwn/              │
│                                 [y] 提取  [n] 留   │
└────────────────────────────────────────────────────┘
```

- 触发面只有四类越界动作（D14）：写宿主 / 用本机凭据 / 改网络策略 / 销毁有成果环境。界内**零打扰**。
- 必须显示**越的是哪条界 + 对象清单**（写哪个路径/用哪个凭据/销毁哪个环境+成果列表）。
- 只有 `y/n`，**没有「永远允许」**——越界不该有惯性。
- 全产品唯一红边框；出现时输入区被模态替换，状态行显示 `y 批准 · n 拒绝`。

## 7. 生命周期

### 7.1 正门（启动屏）

```
┌────────────────────────────────────────────┐
│  今天的研究环境                              │
│                                              │
│  运行中                                      │
│  ❯ pwn-docker    docker · 跑 2h · 有快照     │
│    malware-vm    vm · 隔离网 · 跑 40m        │
│                                              │
│  已停止                                      │
│    ctf-box       docker · 昨 22:00 停        │
│                                              │
│  新建（从环境类型）                             │
│    pwn · fuzz · web · malware · …            │
│                                              │
│  ↑↓ 选 · Enter 进 · Esc 退                   │
└────────────────────────────────────────────┘
```

D17 三语义不变：第一步强制人选、创建权专属人（agent 需要时只能请求）、构建全自动（docker build / VM revert+start，进度上屏，人零动手）。数据源任何一路失败降级为空，首屏永不卡。

### 7.2 跨天续作

`resume` → task.md 状态卡 + 研究记忆注入 → 环境从快照恢复 → 昨天的一切原地复活，死路不重踩。

### 7.3 收尾

提取（越界模态，§6.6）→ 环境销毁（有成果需确认）或 `/snapshot` 留环境。默认一次性、无残留。

## 8. 后台任务：拍肩膀模型

fuzz 转后台后**不开平行窗**（单环境拍板）：

1. 状态行多一段静态存在感：`⛁ fuzz · 3 崩溃`——不呼吸不闪，余光可及、注意力不及。
2. subagent 有**结论**时（不是过程），摘要作为一行插进当前会话流（§5 后台回报行）。直播是噪声，结论是信号；过程细节落环境（`fuzz/crashes/` + task.md），要深挖再去看。
3. 「要我切过去吗」→ 确认后整个会话换到那条线（resume 语义），当前线程靠 task.md + 快照完整保鲜。

手动面：`/bg` 转后台、`/tasks` 看列表即散。数据源：SSE `subagent-*` 事件族（已在 `sse.ts:111-113` 注册，零新契约）。

## 9. 契约与成本（借 tech spec）

**零新契约**（服务端已存在、TUI 侧消费即可）：`chat:tool-result-complete/delta`（工具卡渲染）、`chat:context-usage`（上下文%）、`/chat/queue/force|cancel`、`/chat/rewind`、`/api/admin/term/open`（attach）、env admin API（rollback/snapshot）。

**服务端配套工作（2026-08-16 修订，五项+一处）**：
1. `chat:status` broadcast（chat-engine 一处调用——已在 `sse.ts:94` 注册，成本极低）；
2. **subagent 事件生产**：delegate_task 接回生产路径 + `subagent-*` 事件族产生（sse.ts 已注册但无产生点）——后台拍肩膀的前提；
3. **steering 接线**：pi steering 队列接入 chat-engine（运行中消息注入，M4b 延后项）；
4. **`@` 注入解析**：`/chat/send` 加引用解析（经 env 通道抓内容/元数据注入，小改）；
5. **snapshot/rollback admin 端点**：vm-lifecycle 的 vmrun 原语暴露为 admin API（小改）；
6. **越界 ask 通道**：boundary 增加 ask 态（四类越界动作）+ `boundary:ask` 事件 + `/boundary/respond` 端点（D14 唯一审批，窄通道，不发明新协议）。

**红线不变**（tech spec §3）：不动 SSE 事件名/形状、REST envelope、env-selection 流程、`ansi.ts` 宽度数学；新信号走 `sse.ts` 注册（fail-closed）。**渲染栈：自研 mini-renderer**（行缓冲 + 脏行 diff + ~16ms 帧调度，地基 = `ansi.ts` 宽度数学；零新增依赖——低维护成本优先；Ink 在无模式回看/折叠块内滚动/optimistic 插入上弱区明显，弃用）。

## 11. 落地顺序（2026-08-16 修订）
