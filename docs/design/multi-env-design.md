## 0. 一句话

屏幕照旧专注一个环境（V4 布局不动）；但**所有环境在命令层全部可达**——
看一眼、派个活、拿个产物，都不需要"切过去"。

## 1. 问题与方案（全部命令层/语义层）

| # | 问题 | 方案 | 动什么 |
|---|---|---|---|
| P1 | 非当前环境的状态黑箱 | 现有任务页签行**补 envKey 徽章**（四源行已有 env 数据，纯展示增强）；状态行 env 段已有活性计数 | GUI 微增 |
| P2 | 切环境粗暴（busy 拒绝） | **注视语义**：busy 只锁执行现场，不锁注视——忙碌环境切过去=只读查看（他线只读通道已有），Esc 回，无损 | 服务端闸 + 轻 banner |
| P3 | 跨环境拿产物人工两步 | `/xfer envA:path envB:path`：服务端编排 takeFileFromEnv→受管暂存→putFileToEnv 单命令（全 kind：docker cp/vmrun/scp）；暂存不落用户可见宿主对象，**不触 boundary ask**（与 extract-file/uploads 同口径） | 服务端新端点 + 动词 |
| P4 | ~~并发共享~~ | 非本题（WREN 明示），删 | — |
| P5 | 注册表失序 | 台账治理：同名合并流程 / 本机已有收敛 / `env prune` | 服务端 + 正门小改 |

**跨槽派活**（往任意 idle 环境起 auto-run）：auto-run 启动表单的
"锁环境"从当前环境改为**可选任意环境**——表单小改，不新造视图；
配合 `use` 动词（已有），派活路径 = 表单选环境 或 先 use 再启动，都行。

## 3. 验收判据（锁定）

1. V4 布局零变化（回归：三列/正门/页签/命令中枢原样）

3. 往 idle 环境派活不需移动注视点
4. A→B 产物 = 一条 `/xfer` + 一次越界确认
5. 环境清单零同名双条目
