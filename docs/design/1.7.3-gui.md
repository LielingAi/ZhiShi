# 1.7.3 GUI 界面优化设计

> 状态：定稿待评审
> 范围：环境侧栏呈现优化 + 专家知识页（筛选+翻页）+ 研究记录页（筛选+翻页）
> 纪律：纯呈现层优化——业务逻辑、准入闸、数据流、API 一律不动；model/ 纯函数可单测、组件只接线。

## 1. 目标与边界

- **A（环境侧栏）**：解决三组列表的可读性问题（长名不可区分、冗余标注、组无计数、徽章占位、排序无语义）；
- **B（专家知识页）**：现有纯纵向列表（标题+查看/删除）加**筛选 + 翻页**；
- **C（研究记录页）**：现有纯纵向列表加**筛选 + 翻页**；
- 边界：不改 store 状态结构、不改 API、不改业务判定（accessGate/env-remove/env-down/env-rebuild/env-rename 的 model 逻辑零改动）；筛选/翻页状态只在组件本地。

## 2. A 环境侧栏（EnvSidebar.tsx + model/envs.ts）

### 2.1 长名可区分（主修复）

- 本机已有的镜像行：**recipeId 徽标**（数据已有，`d.recipeId`）——行内显示小徽章 `fuzz` / `code-audit` 等，截断的长名靠它区分；
- 长名截断改**中间省略号**（`zhishi-env-fuzz-a1b2c3d4` → `zhishi-env-fuzz-a…c3d4`）——纯函数 `middleEllipsis(text, max=28)`，悬停 title 仍是全名（既有语义不变）。

### 2.2 组计数

- 组标签带数量：`运行中 2 · 已停止 4 · 本机已有 4`——`groupSidebar` 产出 items 已分组，渲染侧直接取 `items.length`。

### 2.3 徽章紧凑

- 「已登记为 xxx」徽章缩短为「已登记」（悬停 title 显示完整条目名）——视觉行高回落。
- ~~重名去标注~~（实现时撤销：`pwn (pwn)` 括号是条目 name 本身（用户数据）——呈现层不应篡改用户命名，保持原样）。

### 2.4 ~~排序~~（实现时撤销）

- ~~已停止组、本机已有组按最近使用时间降序~~——`EnvEntryLike`/`DiscoveredLike` 类型里没有可靠的
  最近使用字段（updatedAt/lastActiveAt 均未声明），呈现层不造数据语义——维持现状排序。

### 2.5 视觉纪律（不 AI 化）

- 只动 label 组装与渲染细节：CSS 变量沿用现有主题（深浅双主题都有变量），不引入新颜色/动画/图标；
- 徽章样式复用现有 `.cap` 体系，只改文字与 title。

## 3. B 专家知识页（SettingsPage expert tab）

### 3.1 筛选（model 纯函数）

- 新 `model/expert-filter.ts`：`filterExpertEntries(entries, { domain?, kind?, query })`——domain 闭集下拉（全部/binary/pentest/whitebox/ai-security/…）、kind 下拉（全部/idea/technique/sop）；
- 搜索框语义**不变**（现有 expert/search 服务端语义），筛选作用于当前结果集（客户端，组合键 = domain × kind × query）。

### 3.2 翻页（组件本地）

- `PAGE_SIZE = 20`；页码条：`上一页 / 下一页 + 第 n / N 页 · 共 X 条`；筛选/搜索变化时回到第 1 页；
- 纯函数 `paginate(items, page, size)`（clamp 边界）——与 SettingsPage 其他 tab 的控件样式一致（btn small）。

### 3.3 不动区

- 查看详情（expertShow）、删除（expertRm 确认流）、导入（JSON/YAML）、草稿审定（drafts/review）——全部现状保留。

## 4. C 研究记录页（SettingsPage research tab）

### 4.1 筛选

- 下拉：taskKind（全部/binary/pentest/…）+ outcome（全部/success/fail/stuck）；关键词框（命中 summary）；
- 纯函数 `filterResearchEvents(events, { taskKind?, outcome?, query })`（新 `model/research-filter.ts`）——服务端 research/list 当前全量返回（limit 200），筛选客户端组合。

### 4.2 翻页

- 同 3.2（PAGE_SIZE=20，页码条同款）。

## 5. 测试
