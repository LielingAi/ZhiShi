## 1. TUI 能力清单

交互式 TUI = `zhishi agent`（无参数）进入的全屏终端界面。入口链：`src/cli/zhishi.ts:3118-3141`（bare `agent` 分发）→ `src/cli/tui/v2/entry.ts:179-306`（`runAgentLoop` 进程装配）。渲染层冻结于 v2（`src/cli/tui/v2/`，产品代码 7,889 行——v2 ~7.4K + `ansi.ts`/`client.ts` ~0.5K，测试 27 文件 5,826 行）。

### 1.1 入口与进程装配（entry.ts）
- TTY 检查：非 TTY 打印提示并干净退出，不进 alt-screen（`entry.ts:184-187`）。
- 会话绑定：`ensureAgentSession` → `environment/current` 取当前环境分线会话，`/sessions/switch` 切换，失败回落新建 `/sessions`（`entry.ts:153-177`）。
- 终端控制：raw mode + 备用屏（TerminalWriter `enter`）、resize 防抖 50ms（`entry.ts:41-65,242-249`）、SIGINT/SIGTERM/退出清理（`entry.ts:263-305`）。
- 致命异常兜底：先恢复终端再非零退出，防「花屏卡死」（`entry.ts:107-125`）。

### 1.2 渲染层（terminal-writer + chrome + blocks）
- 行级 diff 渲染：`TerminalWriter` 749 行，span 样式 + 行缓存 + 视口滚动（`terminal-writer.ts` 全篇；CJK 双宽在 `ansi.ts`/`chrome.ts:32-56`）。
- 状态栏：phase 旋转符/中断/错误、队列深度、env、子任务段、模型、ctx%、token 计数、右侧提示（`chrome.ts:119-171`）。
- 输入框：盒装提示符 `╭─╮`，软折行 + 光标窗口（最多 8 行）（`chrome.ts:197-296`）。
- 面板：completion/help/history/rewind/queue/tasks 盒装面板 + 滚动窗口 + 溢出提示（`chrome.ts:308-342`）。
- 越界红色模态（唯一红框）：`composeModalBox`（`chrome.ts:380-400`）。
- 消息/工具卡/分隔条/错误行渲染（`blocks/message-block.ts`、`blocks/tool-block.ts`、`blocks/dividers.ts`）。

### 1.3 正门 gate（环境选择）
- 五组选项：运行中 / 已停止 / 本机已有（未注册，选中即登记）/ 新建环境（配方）/ 手动接入（`gate.ts:124-200` `buildGateOptions`）。
- 数据采集：`environment/list|ps|recipes|engines|discover` 五路并行，任一失败降级为空、不阻塞（`gate.ts:81-107`）。
- 提交语义：`environment/select` 是唯一落盘点；已停止环境尽力 `environment/up` 拉起，失败明示（`gate.ts:240-318`）。
- 手动 SSH 三步表单（host→user→keyPath，不落密码，D-T4）：`gate-controller.ts:217-249`，提交 `environment/add`+`select`（`gate-controller.ts:256-300`）。
- Flag 直通：`--env <id>` / `--new-env <recipe>` 跳过正门（`gate.ts:321-347`，接线在 `zhishi.ts:3123-3135`）。

### 1.4 会话流与 SSE 消费（event-reducer.ts）
`event-reducer.ts:126-577` 消费全量事件族（冻结契约）：
- `chat:init`（含重连 replay 前导清理，`event-reducer.ts:135-173`）、`chat:message-chunk|complete|stopped|error`（175-276，含空回复转分隔条、usage/token 累加）、`chat:thinking-start|chunk|complete`（278-324）、`chat:tool-use-start|result-start|result-delta|result-complete`（326-374，含信号提取 `blocks/signal-extract.ts`）、`chat:message-replay`（冷历史回放 + srvId 去重，376-381/674-748）。
- `queue:added|cancelled`（FIFO 队列，383-407）、`chat:steering-added|cancelled`（纠偏队列 + 提示行，409-437）。
- `chat:subagent-started|finished|tool-use|tool-result-*`（拍肩膀模型，439-521）、`chat:bg-started|bg-finished`（长驻进程，470-505）。
- `chat:boundary-ask|boundary-expired`（越界模态，523-537）、`chat:status`、`chat:context-usage`、`chat:system-init`（539-569）。

### 1.5 输入编辑与按键（editor + keymap）
- 行编辑器：多行缓冲、光标、词级移动/删除、kill-ring yank、历史步进（`editor.ts` 291 行）。
- 按键解析：CSI/SS3/kitty 协议、滚轮（SGR mouse）、CJK/emoji、Ctrl 组合（`keymap.ts:49-213`）；bracketed paste 跨 chunk 缓冲（`app.ts:314-347`）。

### 1.6 命令面板与补全
- `/` 命令面板：15 条斜杠命令（`commands.ts:24-40` `SLASH_COMMANDS`），Tab 补全、无参命令直接执行（`app.ts:882-929`）。
- `@` 引用：环境补全（`app.ts:236-251` `refreshAtItems`），文件引用自由输入（`app.ts:1004-1013` `collectRefs`）。
- 帮助面板：12 条键位帮助，Ctrl+L 开关（`commands.ts:47-61`、`app.ts:505`）。

### 1.7 斜杠命令闭环（slash/*）
- `/attach` 终端接管（见 1.14）；`/snapshot` `/rollback` `/extract`（`slash/env.ts:8-76`，extract 走越界 ask 通道）；`/export [sanitize]`（`slash/report.ts:22-53`，`report/export`）；`/model`（状态卡/`set-key` 隐藏输入/`use`/旧语法切换，`slash/model.ts:21-139`）；`/mcp`（状态卡/`-r` 热重载/`enable|disable`，`slash/mcp.ts:20-123`）；`/env`（重进正门）、`/reset`、`/queue`、`/tasks`、`/rewind`、`/fork`、`/help`、`/quit`（`app.ts:1041-1099` `runSlash` 分发）。

### 1.8 会话操作
- rewind：候选消息列表 → `POST /chat/rewind`，本地截断 + 回填编辑框（`app.ts:674-716`）。
- fork：`POST /sessions/fork`，清本地态 + 重启 SSE 泵（`app.ts:722-746`）。

- queue：`GET /chat/queue/status` 面板 + `x` 取消（`app.ts:754-769`、`overlay-reducer.ts:135-149`）。

### 1.9 /tasks 与后台任务
- 子任务 + 长驻进程面板（`app.ts:771-806`），详情页按需拉子代理 transcript（`GET /api/loop-session/messages`，`app.ts:815-840`、`task-transcript.ts:79-172`）。
- 状态栏子任务段（`bg-tasks.ts:44-54` `composeBackgroundSeg`）；完成拍肩膀 + 「要我切过去吗」尾钩字段（`event-reducer.ts:446-468`）。

### 1.10 越界确认（红色模态）
- `chat:boundary-ask` → y/n 模态（`app.ts:935-956`），应答 `POST /chat/boundary/respond`；超时按拒绝关闭（`app.ts:958-965`）。四类 kind：host-write/local-cred/net-policy/destroy-env（`app.ts:1425-1433`）。

### 1.11 中断
- Esc/空输入 Ctrl+C 中断：乐观分隔条 + `POST /chat/stop`，服务端空闲时撤下乐观条（`app.ts:1101-1122`）；`chat:message-stopped` 确认（`event-reducer.ts:240-258`）。

### 1.12 输入历史与回看
- 输入历史持久化到 `~/.zhishi/tui-history.jsonl`（`history.ts:19-66`），↑/↓ 召回（`app.ts:542-550`），Ctrl+R 模糊搜索（子序列评分 `history.ts:72-90`、`app.ts:748-752`、`overlay-reducer.ts:110-125`）。
- 会话回看：PgUp/PgDn/滚轮/Home 滚屏（`app.ts:488-504`），Esc 回底。

### 1.13 断线重连
- SSE 自动重连（线性退避，`client.ts:248-291`）+ 重连指示（`app.ts:257-269`、`chrome.ts:121-123`）+ replay 幂等去重（`event-reducer.ts:135-173,674-748`）。

### 1.14 终端接管 /attach
- 挂起 TUI（退 alt-screen + cooked 模式 + 暂停 stdin）→ spawn 子进程（ssh/docker exec/local shell，`attach.ts:21-54`）→ 子进程退出后恢复 + reflow（`entry.ts:67-104`、`slash/attach.ts:9-41`）。

### 1.15 其他终端形态专属交互
- Esc 草稿恢复槽（清空后可 ↑ 找回一次性草稿，`app.ts:133,529-540`）。

### 4.4 风险评估

1. **桌面入口失活（最高风险）**：1.2.3 起「点图标/托盘/二次实例 → 弹 TUI 终端」是发行版默认交互（`lib.rs:139`、`tray.rs:24-30`、`user-guide.md:29`、`README.md:131`）。退役必须把三个入口**同时**切到 GUI 窗口聚焦，且 `--minimized`（自启）语义保持「不弹窗」。漏改任一处 → 用户点图标无反应。建议退役 PR 与 GUI 窗口聚焦逻辑同批落地 + 实机走查三入口。
2. **`zhishi term` 断链误伤**：term 链路与 TUI 无耦合（§4.1），但执行时若把 `zhishi.ts` 的 term 分支当「TUI 残留」误删，`zhishi term`/`zhishi env open` 会静默失效。退役清单须显式白名单 term/env 分支，并用 `zhishi term open/write/read/close` 实机回归。
3. **bare `zhishi agent` 的调用方**：`zhishi-cli` skill（:269）与部分 AI 编排可能以无参数 `agent` 进入交互。退役后该调用改为打印引导 + 非零退出码提示（不能静默成功），避免 AI 调用方误判「会话已启动」。
4. **SSE 消费面回归**：GUI reducer 已覆盖全部事件族（§2），但 `event-reducer.ts` 承载的 TUI 特有语义（thinking 串台修复、重连活体块清理、乐观分隔条）删除前需人工确认 GUI `reducer.ts` 有对应处理（已核对：`reducer.ts:277-790` 覆盖同族事件）。风险低，建议退役 PR 前跑一次 GUI 全量测试 + 一次重连实机。
5. **输入历史孤儿数据**：`~/.zhishi/tui-history.jsonl` 退役后成孤儿；若 §3.1 补 GUI 历史落盘，可复用同文件或接受从零开始（需在补项里决策）。
6. **打包矩阵回归**：退役执行后的首次发版是「GUI 完整形态 + TUI 退役」叠加（NSIS 显式资源复制 `build_windows.ps1:1156-1166`、三平台 `build:cli` 链路）。删除 `tui_launcher` 后 `cargo check` + 三平台打包冒烟必跑（`resources/cli` 仍需随包分发）。
7. **测试基线变化**：删 27 个测试文件（5,826 行）后全量测试数下降属预期；无功能回归面（TUI 已冻结）。vitest 项目配置无需改（§4.3 #9）。
