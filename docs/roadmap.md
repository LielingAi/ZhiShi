## 1.1.0 —— 能力补齐 + 引擎深化

### 能力补齐

- [x] **MCP 工具接入**：MCP 工具接入引擎（`mcp__<server>__<tool>` 命名、启动即连接、单点失败不阻塞会话）、`mcp/reload` 热重载（配置以磁盘为准，下一轮对话自动生效）、TUI `/mcp` 状态与刷新。完成于 2026-08-19。
- [x] **插件体系移除**：.zsp 加密插件体系整体移除（商业分发时代残留，与开源定位冲突）——扩展统一由 MCP + skills 承担。完成于 2026-08-19。
- [~] **情报横切最小落地**：给引擎一个宿主侧情报检索工具（NVD / exploit-db），先接二进制域。情报源接入方式待定稿。
- [ ] ~~各域 skills 实战深化~~（暂缓：文档性质工作，功能层面优先）

### 引擎深化

- [ ] **后台长驻进程稳定性闭环**：环境内长驻进程通道的稳定性加固（设计底账见 `docs/env-bg-design.md` 未定稿部分）。
- [ ] **经验反喂效果验收**：量化「研究做得越多，下一次是否真的更快」——同域任务对比，决定是否调参。
- [ ] **引擎底座升级回归**：升级前的一键回归检查（当前为手动 smoke 脚本），失败即阻断升级。
